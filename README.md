## Publicar en GitHub Pages

1. Subir el contenido de esta carpeta a la rama `main`.
2. Entrar en **Settings → Pages**.
3. Seleccionar:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
4. Guardar y esperar la publicación.
